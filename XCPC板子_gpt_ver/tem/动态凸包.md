# 动态凸包竞赛板子

默认 C++17。本文件只保留两种在线插入、可直接提交的实现：动态点凸包，以及动态直线上包络。二者都用平衡树，支持任意插入顺序。第 1 节复用《计算几何_二维.md》的 `Point<T>` 与 `cross128` 定义（复制该文档的 0、1.2 节）；第 2 节的 `HullLine` 是函数图像 `y=kx+b`，不要与几何直线 `Line<T>` 混用。

## 0. 选型

| 需求 | 复制章节 | 复杂度 |
|---|---|---|
| 在线插入整数点、判断点是否在当前凸包内 | 1 | 插入均摊 `O(log n)`，查询 `O(log n)` |
| 在线插入整数直线、查询某个整数 `x` 处最大值 | 2 | 插入均摊 `O(log n)`，查询 `O(log n)` |
| 查询最小值 | 2，将 `k,b` 同时取反 | 同上 |

两份实现互相独立。点凸包只维护严格上下链，边上的中间点会被删除；直线凸包只保留真正可能成为最大值的直线。

## 1. 在线插入点：上下链

坐标类型为 `long long`，叉积使用 `__int128`。`add(p)` 插入点；`contains(p)` 判断点在闭凸包内，边界返回 `true`；`getHull()` 按逆时针返回当前凸包，不重复首点。

同一横坐标在上链只保留最高点，在下链只保留最低点。每个点至多被插入、删除一次，因此连续插入总复杂度为 `O(n log n)`，单次均摊 `O(log n)`。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using i128 = __int128_t;
using P = Point<ll>;            // 与二维板子的 Point<T> 对齐

struct DynamicHull {
    struct Chain {
        bool up;                 // true: 上链；false: 下链
        map<ll,ll> s;            // x -> y

        using It = map<ll,ll>::iterator;
        P pt(It it) const { return {it->first, it->second}; }

        bool bad(It it) {        // 中间点不属于严格链
            if (it == s.begin() || next(it) == s.end()) return false;
            i128 z = cross128(pt(prev(it)), pt(it), pt(next(it)));
            return up ? z >= 0 : z <= 0;
        }

        void add(P p) {
            auto it = s.lower_bound(p.x);
            if (it != s.end() && it->first == p.x) {
                if (up ? it->second >= p.y : it->second <= p.y) return;
                it->second = p.y;
            } else {
                it = s.emplace_hint(it, p.x, p.y);
            }

            if (bad(it)) { s.erase(it); return; }
            while (it != s.begin()) {
                auto q = prev(it);
                if (!bad(q)) break;
                s.erase(q);
            }
            while (next(it) != s.end()) {
                auto q = next(it);
                if (!bad(q)) break;
                s.erase(q);
            }
        }

        bool covers(P p) const { // 上链要求 p 在链下；下链要求 p 在链上
            if (s.empty()) return false;
            auto it = s.lower_bound(p.x);
            if (it == s.end()) return false;
            if (it->first == p.x)
                return up ? p.y <= it->second : p.y >= it->second;
            if (it == s.begin()) return false;
            auto a = prev(it);
            i128 z = cross128(P{a->first,a->second}, P{it->first,it->second}, p);
            return up ? z <= 0 : z >= 0;
        }
    } hi{true,{}}, lo{false,{}};

    void add(P p) { hi.add(p); lo.add(p); }
    bool contains(P p) const { return hi.covers(p) && lo.covers(p); }

    vector<P> getHull() const { // 逆时针；点/线段退化时返回 1/2 个点
        vector<P> h;
        for (auto [x,y] : lo.s) h.push_back({x,y});
        for (auto it=hi.s.rbegin(); it!=hi.s.rend(); ++it) {
            P p{it->first,it->second};
            if (h.empty() || !(h.back()==p)) h.push_back(p);
        }
        if (h.size()>1 && h.front()==h.back()) h.pop_back();
        return h;
    }
};
```

用法：

```cpp
DynamicHull h;
h.add({0,0}); h.add({2,0}); h.add({1,2});
cout << h.contains({1,1}) << '\n'; // 1
vector<P> poly = h.getHull();       // 逆时针凸包
```

注意：

- 这是插入型结构，不支持删除历史点。
- `contains` 可在任意时刻调用；空集返回 `false`。
- 作差前已经转为 `i128`；仍需保证叉积本身不超过有符号 `i128` 范围，常见 `|坐标| <= 1e18` 可安全使用。

## 2. 在线插入直线：`LineContainer`

维护直线 `y=kx+b` 的最大值，斜率、截距和查询横坐标均为 `long long`。插入和询问顺序完全任意。交点横坐标用向下取整的整数断点保存，函数值用 `__int128` 返回，避免 `k*x+b` 溢出。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using i128 = __int128_t;

struct HullLine {
    ll k, b;
    mutable i128 p;             // 本线最优区间的右端点（整数，含端点）
    bool operator<(const HullLine& o) const { return k < o.k; }
    bool operator<(ll x) const { return p < x; }
};

struct LineContainer : multiset<HullLine, less<>> {
    static constexpr i128 INF = (i128)1 << 126;

    static i128 divFloor(i128 a, i128 b) { // floor(a/b), b != 0
        if (b < 0) a = -a, b = -b;
        if (a >= 0) return a / b;
        return -((-a + b - 1) / b);
    }
    bool isect(iterator x, iterator y) {
        if (y == end()) { x->p = INF; return false; }
        else if (x->k == y->k) x->p = x->b > y->b ? INF : -INF;
        else x->p = divFloor((i128)y->b-x->b, (i128)x->k-y->k);
        return x->p >= y->p;
    }

    void add(ll k, ll b) {       // 加入 y = kx+b，维护最大值
        auto z = insert({k,b,0}), y = z++, x = y;
        while (isect(y,z)) z = erase(z);
        if (x != begin() && isect(--x,y)) isect(x, y=erase(y));
        while ((y=x) != begin() && (--x)->p >= y->p)
            isect(x, erase(y));
    }

    i128 query(ll x) const {     // 调用前保证非空
        auto l = *lower_bound(x);
        return (i128)l.k*x + l.b;
    }
};
```

用法：

```cpp
LineContainer cht;
cht.add(2, 3);
cht.add(-1, 7);
i128 ans = cht.query(5);         // max(2*5+3, -5+7) = 13

// 求最小值：插入 (-k,-b)，答案再取负。
// i128 mn = -chtMin.query(x);
```

若答案要输出，可使用：

```cpp
void print128(i128 x) {
    if (x < 0) cout << '-', x = -x;
    if (x >= 10) print128(x / 10);
    cout << char('0' + x % 10);
}
```

### 2.1 对偶理解

点 `(k,b)` 与直线 `y=kx+b` 对偶。插入一条线等价于插入一个参数点；在横坐标 `x` 查询最大值，等价于查询参数点集与方向 `(x,1)` 的最大点积。因此很多“插入点，查询 `a*x+b*y`”的问题可先根据查询方向做对偶变形，再套本结构。

### 2.2 易错点

- 相同斜率无需特判，结构会自动只留下截距最大的线。
- 断点必须向下取整，C++ 的负数除法是向零截断，不能直接写 `/`。
- `query` 返回 `i128`。若强转回 `long long`，必须先确认答案范围。
- 断点也用 `i128`，不需要钳制，查询可包含 `LLONG_MIN`、`LLONG_MAX`。求最小值时若参数为 `LLONG_MIN`，不能直接在 `ll` 内取负。
- 只查询浮点 `x` 时不能直接用这个整数断点版本；应改为 `long double` 交点，或使用离散横坐标李超树。
- 该结构是插入型上包络，不支持删除任意历史直线。
