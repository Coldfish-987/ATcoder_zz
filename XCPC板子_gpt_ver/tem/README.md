## 使用顺序

1. 先看目标文件顶部的选择表，确认数据范围和前置条件。
2. 只复制当前功能对应的代码块及其明确写出的依赖。
3. 检查下标起点、模数、无穷大、是否允许负边/重边/空方案。
4. 对复杂模块先用最小样例和随机暴力对拍，再提交题目版本。

## 有意不收录

- 普通、懒标记、可持久化等线段树由使用者自行编写；库中只保留用途明确的李超树。
- 模拟退火、随机爬山、通用插头 DP 等高度依赖题意的代码不作为固定模板。
- 支配树、一般仙人掌、一般拟阵交、单纯形、字符串 runs、松弛卷积等低频长模块暂不进入主库；遇到明确题型时单独准备，避免主库失去可检索性。
- 同一算法的低性能教学版和高性能提交版不重复保留，优先保留边界清楚且可验证的一版。
