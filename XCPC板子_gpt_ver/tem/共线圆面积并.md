# 共线圆面积并：在线插入

默认 C++17。维护一组圆心在同一直线上的圆盘，每插入一个圆后可 `O(1)` 取得当前面积并。插入均摊 `O(log n)`，总复杂度 `O(n log n)`。

代码按圆心在 `x` 轴上，即圆为 `(x,0,r)` 编写。若圆心满足 `x=0`、位于 `y` 轴，只需把圆心的 `y` 坐标作为代码中的 `x` 传入；旋转或交换坐标不改变面积。

## 1. 原理

圆 `(x_i,0,r_i)` 的上半圆满足

```text
y^2 = r_i^2 - (X-x_i)^2
    = -X^2 + 2*x_i*X + (r_i^2-x_i^2).
```

所有圆都有相同的 `-X^2`，所以在固定 `X` 处比较高度，只需比较直线

```text
f_i(X) = 2*x_i*X + (r_i^2-x_i^2).
```

结构按斜率，也就是圆心横坐标维护这些直线的上包络。每个包络节点只在相邻直线交点之间贡献圆弧面积，并把区间截到圆自己的定义域 `[x_i-r_i,x_i+r_i]`。

对整圆上下两半一起积分，原函数为

```text
F(t) = t*sqrt(r^2-t^2) + r^2*asin(t/r).
```

于是圆在 `[L,R]` 的贡献是 `F(R-x)-F(L-x)`。

---

## 2. 可直接复制的板子

`add(x,r)` 在线加入圆盘；`area()` 返回所有已加入圆盘的并面积。半径非正的圆会被忽略，同心圆只保留最大半径。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ld = long double;

struct CollinearCircleUnion {
    static constexpr ld INF = numeric_limits<ld>::infinity();

    struct C {
        ld x, r, a = 0;          // 圆心、半径、缓存的区间面积
    };
    map<ld,C> h;                 // 只存上包络，按圆心 x 排序
    ld sum = 0;
    using It = map<ld,C>::iterator;

    static ld rightCut(const C& a, const C& b) { // 交点相对 a.x；a.x < b.x
        ld d = b.x-a.x;
        return d/2 + (a.r-b.r)*(a.r+b.r)/(2*d);
    }
    static ld leftCut(const C& a, const C& b) { // 交点相对 b.x；a.x < b.x
        ld d = b.x-a.x;
        return -d/2 + (a.r-b.r)*(a.r+b.r)/(2*d);
    }
    static ld primitive(ld t, ld r) {
        t = max(-r, min(r, t));
        ld q = max((ld)0, (r-t)*(r+t));
        return t*sqrtl(q) + r*r*asinl(max((ld)-1, min((ld)1, t/r)));
    }

    ld value(It it) const {      // 当前相邻交点限定出的圆弧面积
        ld L = -INF, R = INF;
        if (it != h.begin()) L = leftCut(prev(it)->second, it->second);
        auto nx = next(it);
        if (nx != h.end()) R = rightCut(it->second, nx->second);
        const C& c = it->second;
        L = max(L, -c.r);
        R = min(R, c.r);
        if (L >= R) return 0;
        return primitive(R,c.r) - primitive(L,c.r);
    }

    bool bad(It it) const {      // 本直线在上包络没有正长度区间
        if (it == h.begin() || next(it) == h.end()) return false;
        auto a = prev(it), c = next(it);
        return leftCut(a->second,it->second) >= rightCut(it->second,c->second);
    }

    void pull(It it) {
        sum -= it->second.a;
        sum += it->second.a = value(it);
    }

    void eraseAt(It it) {
        auto l = it == h.begin() ? h.end() : prev(it);
        auto r = next(it);
        sum -= it->second.a;
        h.erase(it);
        if (l != h.end()) pull(l);
        if (r != h.end()) pull(r);
    }

    It insertRaw(C c) {
        auto r = h.lower_bound(c.x);
        auto l = r == h.begin() ? h.end() : prev(r);
        auto it = h.emplace_hint(r, c.x, c);
        if (l != h.end()) pull(l);
        pull(it);
        if (r != h.end()) pull(r);
        return it;
    }

    void add(ld x, ld r) {       // 加入圆盘 (x,0,r)
        if (r <= 0) return;

        auto same = h.find(x);
        if (same != h.end()) {
            if (same->second.r >= r) return;
            eraseAt(same);       // 新同心圆完全覆盖旧同心圆
        }

        C c{x,r};
        auto nx = h.lower_bound(x);
        if (nx != h.begin() && nx != h.end()
            && leftCut(prev(nx)->second,c) >= rightCut(c,nx->second)) return;
        It it = insertRaw(c);

        while (it != h.begin()) {
            auto q = prev(it);
            if (!bad(q)) break;
            eraseAt(q);
        }
        while (next(it) != h.end()) {
            auto q = next(it);
            if (!bad(q)) break;
            eraseAt(q);
        }
    }

    ld area() const { return max((ld)0, sum); }
};
```

用法：

```cpp
CollinearCircleUnion cu;
cout << fixed << setprecision(12);
for (int i=0; i<n; ++i) {
    long double x, r;
    cin >> x >> r;
    cu.add(x,r);
    cout << cu.area() << '\n';
}
```

## 3. 正确性与复杂度要点

- 对每个横坐标，最高圆弧等价于直线 `2*x_i*X+r_i^2-x_i^2` 的上包络；当包络值减去 `X^2` 为负时没有圆覆盖，该情况由圆定义域截断自动排除。
- 相邻包络直线的交点严格递增。插入后，交点次序不合法的节点永远不会再次成为上包络，因此可以永久删除。
- 每个圆最多进入和离开包络一次；平衡树操作为 `O(log n)`，所以 `n` 次插入总计 `O(n log n)`。
- `sum` 直接维护各节点当前有效区间的积分。插入或删除节点时，只需重算它和左右邻居，`area()` 为 `O(1)`。

## 4. 边界与精度

- 使用 `long double`、`sqrtl`、`asinl`，通常输出 `setprecision(12)` 或更高。
- 交点与积分都在当前圆心的相对坐标中计算，不直接相减 `r^2-x^2`，避免圆心很大、半径很小时的消减；缓存旧贡献减少积分常数。`long double` 不是任意精度，不能在缺少数据范围时保证绝对误差 `1e-9`。
- `map` 的键使用圆心坐标的精确值，输入中“同心”也必须表示为完全相同的数。若题目给整数或固定小数，这一约定自然成立。
- 这是只插入结构，不支持删除已经加入的圆。
- 本板子只适用于所有圆心共线。任意圆面积并应使用圆弧事件合并，复杂度通常为 `O(n^2 log n)`。
- 若题目只给一批圆、只需最终答案，也可以按任意顺序调用 `add`，最终 `area()` 不受插入顺序影响。
